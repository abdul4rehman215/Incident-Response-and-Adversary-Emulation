# 📘 Interview Q&A — Lab 6: Analyzing DNS Traffic

---

## Q1. Which command is used to capture live DNS traffic on Linux?

**Answer:**  
```bash
tcpdump -i <interface> -n port 53
````

This captures DNS traffic on port 53 without hostname resolution.

---

## Q2. How can DNS traffic be saved for offline analysis?

**Answer:**

```bash
tcpdump -i ens5 -w dns_capture.pcap port 53
```

This creates a PCAP file for later forensic analysis.

---

## Q3. What is a DGA domain?

**Answer:**
A DGA (Domain Generation Algorithm) domain is automatically generated by malware.
They are typically:

* Long
* Random-looking
* High consonant-to-vowel ratio
* Frequently changing

Malware uses them for Command-and-Control (C2) communication.

---

## Q4. How was DGA detection implemented in this lab?

**Answer:**
By analyzing the first subdomain label and checking:

* Length greater than 12 characters
* Consonants significantly higher than vowels

Example logic:

```python
if len(sub) > 12 and consonants > vowels * 3:
```

## Q5. What indicates possible DNS beaconing behavior?

**Answer:**
Repeated DNS queries:

* To the same domain
* At consistent time intervals
* With low standard deviation in timing

Beaconing is commonly used by malware communicating with C2 servers.

---

## Q6. What are common indicators of DNS tunneling?

**Answer:**

* High query volume
* Large number of unique subdomains
* Long domain lengths
* Excessive TXT record queries (type 16)
* High entropy subdomain strings

These patterns indicate potential data exfiltration via DNS.

---

```python
from scapy.all import rdpcap, DNS
```

## Q8. Why is baseline comparison important in DNS analysis?

**Answer:**

Baseline comparison helps detect:

* New domains
* Volume spikes
* Unusual query types
* Behavioral deviations

It reduces false positives and improves anomaly detection accuracy.

---

## Q9. What DNS query type is commonly abused in tunneling attacks?

**Answer:**
**TXT records (Type 16)**

TXT queries allow larger payload sizes, making them ideal for covert data exfiltration.

---

## Q10. Why is DNS monitoring critical in threat detection?

**Answer:**

Because DNS is used by:

* Malware C2 communication
* Data exfiltration
* DGA-based botnets
* Beaconing implants
* Phishing infrastructure

DNS often reveals compromise before other logs do.

---

## Q11. What is the difference between offline and real-time DNS analysis?

**Answer:**

| Offline Analysis       | Real-Time Monitoring      |
| ---------------------- | ------------------------- |
| Uses PCAP files        | Uses live packet sniffing |
| Forensic investigation | Active detection          |
| Post-incident review   | Immediate alerting        |

Both are essential in SOC environments.

---

## Q12. What is DNS exfiltration?

**Answer:**

DNS exfiltration is a technique where attackers encode sensitive data into DNS queries and send it to attacker-controlled domains.

Example:

```
base64-data.attacker-domain.com
```

It bypasses many firewalls because DNS is usually allowed outbound.

---

## Q13. What does high entropy in subdomains indicate?

**Answer:**

High entropy suggests:

* Encoded data
* Randomized DGA domains
* Possible tunneling activity

Entropy analysis is a strong DGA detection technique.

---

## Q14. Why are suspicious TLDs (.tk, .ml, .ga) monitored?

**Answer:**

Some low-cost or free TLDs are frequently abused for:

* Malware hosting
* Phishing campaigns
* Temporary C2 domains

Monitoring these improves detection coverage.

---

## Q15. How can DNS logs support incident response?

**Answer:**

DNS logs help:

* Identify infected hosts
* Trace malware C2 domains
* Detect data exfiltration attempts
* Build attack timelines
* Support forensic investigations
